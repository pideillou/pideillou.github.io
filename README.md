# Portfolio de PIDEILLOU

Portfolio statique construit avec Vite et Tailwind CSS v4, en JavaScript natif, pensé d'abord pour le mobile.

## Prérequis

- [Node.js](https://nodejs.org/) 20.19 ou plus récent.

## Commandes

```bash
npm install       # installe les dépendances (une fois)
npm run dev       # lance le site sur http://localhost:5173/
npm run build     # génère le site final dans dist/
npm run preview   # affiche le site final pour le tester
```
